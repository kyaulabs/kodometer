# Kodometer 0.1.0

The first native Kodometer release brings AI usage monitoring to KDE Plasma 6.4 and newer on Linux, under Wayland or X11. Collection uses Qt Network; the widget never executes provider CLIs or reads browser sessions.

## Providers

| Provider | Usage and authentication |
| --- | --- |
| Codex | OAuth quota from existing Codex credentials; named credential folders |
| Claude | OAuth session, weekly, model, and spending limits; named credential folders |
| Gemini | Supported Workspace, education, and licensed Code Assist OAuth quotas; named credential folders |
| DeepSeek | API balance, including funded non-USD currencies; named KWallet accounts |
| Kimi Code | Kimi For Coding quotas; named KWallet keys or Default read-only CLI credential reuse |
| OpenRouter | Prepaid credits, optional key limits, and Management Activity; named KWallet key pairs |
| xAI | Developer Management API balance and optional daily spend; named key/team pairs in KWallet |
| z.ai / BigModel CN | Regional personal/team quota and optional analytics/balance; named KWallet keys and selectors |

Only the selected profile/account for each enabled provider is polled. Named selections do not inherit another account's credentials. OAuth renewal stays with the request's originating credential file.

## Widget features

- Overview and provider details, quota/reset indicators, balances, and keyboard navigation.
- Immediate per-widget account switching, including recovery without usage data.
- Configurable automatic refresh, provider enablement, and idle-window filtering.
- Opt-in low-quota notifications based on fresh successful results.
- Transient daily-spend charts for xAI and OpenRouter, without extra API requests or billing-history files.
- Explicit dashboard/documentation actions using fixed official HTTPS destinations.

## Installation and limits

The downloadable Linux x86_64 archive is built on rolling Arch Linux. It does not bundle dependencies and is not a universal binary for other Qt, KDE, or glibc versions. Build from source on other distributions using compatible development packages. See the [installation and upgrade instructions](https://github.com/kyaulabs/kodometer/blob/v0.1.0/README.md#build-and-install).

Verify the archive checksum, and stop Plasma before replacing a loaded plugin. The plugin ID is `org.kyaulabs.kodometer`; development installations using the former `org.kyaulabs.codexbar` ID must add the renamed widget. Existing Kodometer profiles, account UUIDs, and wallet entries need no migration.

API keys entered through the widget stay in KWallet. The widget does not provide interactive provider sign-in. Gemini API-key/Vertex sessions and retired consumer tiers are unsupported; xAI covers developer billing, not Grok/SuperGrok; Kimi covers For Coding, not Moonshot/Open Platform. Provider APIs and credential formats can change independently of this release.

The archive checksum detects corruption, not publisher identity. See [security and privacy](https://github.com/kyaulabs/kodometer/blob/v0.1.0/README.md#security-and-privacy) before configuring credentials.
