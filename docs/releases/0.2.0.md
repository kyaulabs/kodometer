# Kodometer 0.2.0

Kodometer 0.2.0 adds native x86-64 packages for Arch Linux, Ubuntu 26.04 LTS, and Fedora 43/44. Each distribution builds against its own Qt, KDE, and glibc libraries. The widget's eight providers, authentication behavior, and selected-only account polling are unchanged.

## Packages

| System | Package |
| --- | --- |
| Arch Linux | `kodometer-0.2.0-1-x86_64.pkg.tar.zst` |
| Ubuntu 26.04 LTS | `kodometer_0.2.0-1ubuntu26.04_amd64.deb` |
| Fedora 43 | `kodometer-0.2.0-1.fc43.x86_64.rpm` |
| Fedora 44 | `kodometer-0.2.0-1.fc44.x86_64.rpm` |

The release also includes a source archive, an AUR recipe bundle containing `PKGBUILD` and `.SRCINFO`, and the legacy Arch-built Linux archive. Each payload has an individual `.sha256` file; `kodometer-0.2.0-SHA256SUMS` lists all seven payloads.

AUR recipes pin the release source archive and its SHA-256 digest. Recipe availability does not mean the package has been published to AUR: automatic AUR pushes require separately configured ownership and dedicated SSH/GPG credentials. Those are not configured for this release preparation.

## Validation and publication

All four distribution builds run the native tests in Release mode. Separate runtime containers install and reinstall each package and launch the installed plugin in an isolated Plasma session without development dependencies or provider credentials. This work also fixes four HTTP test fixtures whose server startup calls were previously removed by optimized builds.

Publication requires the complete package inventory. Draft assets are downloaded, checked against their checksums, and compared with build outputs before the release becomes public. Retries never replace already-published assets. Optional AUR updates use GPG-signed commits, do not force-push, and cannot downgrade a newer AUR version.

## Installation and upgrade

Plasma 6.4 or newer is required. Only x86-64 is targeted (`amd64` in DEB metadata). Ubuntu 24.04, ARM, generic Debian/RHEL compatibility, and hosted APT/DNF repositories are not included. Dependencies are not bundled; choose the package for your distribution rather than reusing the Arch binary on Ubuntu or Fedora.

Download a package and its checksum from this release. Verify the checksum, then install with `apt`, `dnf`, or `pacman` as described in the [native package guide](https://github.com/kyaulabs/kodometer/blob/v0.2.0/docs/packaging.md). Checksums detect corruption, not publisher identity; DEB/RPM files are not independently signed by this workflow.

Log out of Plasma before replacing a loaded plugin and install from a TTY or SSH session. Remove duplicate manual system or user-local installations before switching to a managed package. Widget preferences, OAuth files, and KWallet entries need no migration and are not removed by the packages. The published v0.1.0 archive remains unchanged.
