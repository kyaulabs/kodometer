# Kodometer 0.2.1

Kodometer 0.2.1 fixes native control layout and provider usage presentation. It is a patch release: authentication, selected-only polling, supported distributions, and stored configuration remain unchanged.

## Fixes

- Center provider-tab icons and text.
- Remove doubled profile/account selector text in the widget and settings while preserving plain-text names and native KDE styling.
- Keep vertical scrollbars clear of provider details and Overview content.
- Distinguish API-reported Codex Pro ($200/month tier) from Pro-Lite ($100/month tier). These labels describe tiers, not invoice amounts.
- Show available Codex banked resets in both provider details and Overview when the count is at least one. Reading this count adds no requests and never consumes a reset.
- Accept OpenRouter's deprecated request-rate sentinel (`requests: -1`) without rejecting otherwise valid key usage and spending caps.

OpenRouter Management Activity still needs a separate Management key. Default credentials and named accounts do not share missing keys; see the [credential instructions](https://github.com/kyaulabs/kodometer/blob/v0.2.1/README.md#requirements).

Kimi Code's website **Total usage** remains unsupported. A compatibility test with an official device-code OAuth login retrieved Coding quotas but received HTTP 401 from the separate subscription endpoint. This release does not collect website tokens or browser sessions.

## Packages and upgrade

Native x86-64 packages remain available for Arch Linux, Ubuntu 26.04 LTS, and Fedora 43/44. Plasma 6.4 or newer is required. The release includes source and AUR recipe archives, the Arch package and legacy Linux archive, an Ubuntu DEB, and both Fedora RPMs. Each payload has a SHA-256 sidecar; `kodometer-0.2.1-SHA256SUMS` covers all seven payloads.

Follow the [native package guide](https://github.com/kyaulabs/kodometer/blob/v0.2.1/docs/packaging.md). Log out of Plasma before replacing a loaded plugin; install from a TTY or SSH session, then log back in. No credential or preference migration is needed. Existing public releases remain unchanged.

AUR recipes are included, but automatic AUR publication remains unconfigured. Checksums detect corruption, not publisher identity; DEB/RPM files are not independently signed by this workflow.
