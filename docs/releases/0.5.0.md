# 🚀 Kodometer 0.5.0

## ✨ Highlights

Kodometer 0.5.0 adds per-provider colors and fixes the popup layout reported after 0.4.0. Overview hover backgrounds now contain their bars with padding, short tabs no longer retain excess height, and over-tall content uses numbered inner pages instead of vertical scrolling.

This is a minor release after 0.4.0: `feat: add provider colors and content-sized popup pages` makes `git-cliff --bumped-version --use-branch-tags` select `v0.5.0`. No credential, account, or history migration is required, and there is no new runtime dependency. Two UI changes are deliberate: profile/account selection moves to settings, and panel bars use the limiting provider's accent rather than a single shared accent.

## 🚀 Features

- **Per-provider accents:** open **Configure Kodometer… → General → Providers** and choose a color under each provider. It colors the provider tab's accent stripe, Overview and detail quota bars, quota/spend history, and panel meters. **Use default color** restores the built-in provider accent. Overrides start empty and follow per-widget Apply/Cancel/Defaults; changing a color does not refresh a provider or modify its stored observations.
- **Consistent panel colors:** compact session and weekly bars use the provider supplying the most constrained quota. Donuts keep differently colored nested rings derived from the provider accent. An explicit provider color takes precedence over legacy Session/Weekly donut overrides; those saved overrides are retained and apply again when the provider override is cleared.
- **Inner page tabs:** popup width remains stable while height follows the selected content. When a view exceeds the available screen budget, **Page 1**, **Page 2**, and further tabs appear inside it. Pages break between sections where possible and follow keyboard focus. Overview now includes all enabled providers with data, rather than limiting the list to six.

## 🐛 Fixes

- Overview rows calculate their height from the full content plus explicit padding. Quota bars no longer bleed below the hovered row's background.
- Popup minimum, preferred, and maximum heights follow the selected content. Switching from quota/history to a shorter balance view no longer preserves a tall blank area. The height budget uses the applet's available screen rectangle.
- Provider pages have no vertical scrollbar or reserved scrollbar gutter. Exceptionally tall sections continue on another numbered page rather than becoming inaccessible.
- The footer's confirmed **Clear quota history…** icon is the only history-reset control. The duplicate **Clear saved quota history…** chart button is removed; clearing still affects all locally recorded quota history and never credentials or provider-reported spend history.
- **Open dashboard** and **Documentation** now follow usage and history. Profile/account selectors move out of the popup into **OAuth profiles** and **KWallet accounts** settings. The footer configuration icon opens settings even without usage data; selections take effect with Apply.

## 🛠️ Installation and upgrade

Download the matching native package and checksum from this release. **Log out of Plasma before replacing the loaded plugin**, install from a TTY or SSH session, then log back in.

```sh
# Arch Linux
sha256sum -c kodometer-0.5.0-1-x86_64.pkg.tar.zst.sha256
sudo pacman -U ./kodometer-0.5.0-1-x86_64.pkg.tar.zst

# Ubuntu 26.04 LTS
sha256sum -c kodometer_0.5.0-1ubuntu26.04_amd64.deb.sha256
sudo apt install ./kodometer_0.5.0-1ubuntu26.04_amd64.deb

# Fedora 43
sha256sum -c kodometer-0.5.0-1.fc43.x86_64.rpm.sha256
sudo dnf install ./kodometer-0.5.0-1.fc43.x86_64.rpm

# Fedora 44
sha256sum -c kodometer-0.5.0-1.fc44.x86_64.rpm.sha256
sudo dnf install ./kodometer-0.5.0-1.fc44.x86_64.rpm
```

Keep the same installation method and prefix. Remove manual system or user-local duplicates before switching to a native package, so Qt cannot load an older plugin. Existing selections, credentials, preferences, and quota observations need no migration. Select profiles/accounts in settings after upgrading; Cancel discards staged selection changes, but wallet saves/removals remain immediate.

See the [0.5.0 package guide](https://github.com/kyaulabs/kodometer/blob/v0.5.0/docs/packaging.md) and [tagged build instructions](https://github.com/kyaulabs/kodometer/blob/v0.5.0/README.md#build-and-install) for source recipes and prefix-sensitive installation. Container provisioning scripts are not desktop installers. Removing a package does not delete credentials, preferences, or the user-owned history file.

## ⚠️ Compatibility and known limitations

- The compiled applet requires **Plasma/libplasma 6.4+**, Qt 6.4+ and KDE Frameworks 6. Use the compatible Qt/KDE versions supplied by the supported distribution. Binary targets remain Arch rolling, Ubuntu 26.04 LTS, and Fedora 43/44 on x64. There are no ARM, generic Debian, or RHEL packages; Ubuntu 24.04's standard Plasma stack is too old.
- Packages are distribution/ABI-specific. There is no hosted APT/DNF repository or automatic desktop updater. Compiled applets are not `kpackagetool6` ZIPs.
- Settings dialogs can still scroll. Popup pages avoid vertical scrolling; very tall individual sections can span continuation pages, and smaller screens can require more than two pages. Provider-tab navigation can still scroll horizontally when many providers are enabled.
- Color overrides affect presentation, not provider logos, desktop selection backgrounds, notifications, credential discovery, or polling. Ring colors remain distinct by window. The shared bar-accent setting is now a fallback when no provider accent is available.
- Only selected profiles/accounts are polled. Native authentication limits are unchanged: Gemini is Code Assist OAuth quota, Kimi is For Coding rather than Moonshot, and xAI is Management API billing rather than Grok subscriptions. Quota history remains observed-only and bounded to 30 days; billing history remains transient. See the [tagged provider contract](https://github.com/kyaulabs/kodometer/blob/v0.5.0/README.md).

## 🔒 Security and privacy

No authentication endpoints, credential handling, notification policy, or history-storage rules change. Provider colors are nonsecret per-widget RGB preferences applied to copied presentation maps. Manual secrets and private selectors stay in KWallet; OAuth renewal remains pinned to its originating provider-owned file. There are no provider CLI executions, browser-session reads, extra history requests, or new chart dependencies.

The single history-clear icon still asks for confirmation before deleting observations across all providers, profiles, and accounts. Credentials, widget preferences, and provider-reported billing history are unchanged. Packages never remove these user-owned files.

Published assets are immutable. SHA-256 files detect corruption but do not establish publisher identity. The workflow creates an annotated source tag, not an independently GPG-signed tag, and does not independently sign DEB/RPM files. Reviewed development commits retain their GPG signatures through merge commits.
