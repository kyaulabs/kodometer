# 🚀 Kodometer 0.6.0

## ✨ Highlights

Kodometer 0.6.0 makes quota history continuous and inspectable. The chart carries the last known percentage through polling gaps, and hovering shows the time and percentage at the pointer. Provider tabs have balanced vertical padding, the settings icon is smaller, and the header wordmark is centered by its visible artwork.

This is a minor release after 0.5.1. The `feat(ui): inspect continuous quota history and balance popup controls` commit adds hover inspection; `git-cliff --bumped-version` selects `v0.6.0`. The earlier `fix(ui)` commit corrects history connections and wordmark placement. There are no breaking API changes, new dependencies, or credential/history migrations. Chart presentation changes as described below; stored observations do not change.

## 🚀 Features

Quota-provider details now show a vertical position guide and a point marker when the pointer is over recorded history. A popup displays the selected time and the last observed remaining percentage at that time. This works in the existing 24-hour, 7-day, and 30-day views without enabling a setting or making another request.

The percentage is the last known value, not proof of activity during an unobserved interval. Markers and the popup disappear before the first known observation and when the pointer leaves the plot. Provider-reported daily spend charts are unchanged.

## 🐛 Fixes

- Quota-history lines and background fill no longer have blank intervals between observations. The last percentage extends horizontally to the next observation and through the end of the view. A retained observation before the selected range supplies its left edge when available; nothing is drawn before the first known sample.
- Drops, quota increases, and resets appear as vertical steps at the observation timestamp, rather than disconnected line segments or gradual interpolated recovery. A single observation can extend horizontally without manufacturing stored samples.
- Provider-tab icon/label groups use equal top and bottom padding instead of inheriting asymmetric theme padding.
- The settings glyph is two logical pixels smaller than the other footer action icons, balancing its apparent size.
- The header compensates for unequal whitespace inside the supplied SVG, centering the visible wordmark without modifying the artwork.

## 🛠️ Installation and upgrade

Download your distribution's package and checksum from this release. Log out of Plasma before replacing its loaded plugin, install from a TTY or SSH session, then log back in.

```sh
# Arch Linux
sha256sum -c kodometer-0.6.0-1-x86_64.pkg.tar.zst.sha256
sudo pacman -U ./kodometer-0.6.0-1-x86_64.pkg.tar.zst

# Ubuntu 26.04 LTS
sha256sum -c kodometer_0.6.0-1ubuntu26.04_amd64.deb.sha256
sudo apt install ./kodometer_0.6.0-1ubuntu26.04_amd64.deb

# Fedora 43
sha256sum -c kodometer-0.6.0-1.fc43.x86_64.rpm.sha256
sudo dnf install ./kodometer-0.6.0-1.fc43.x86_64.rpm

# Fedora 44
sha256sum -c kodometer-0.6.0-1.fc44.x86_64.rpm.sha256
sudo dnf install ./kodometer-0.6.0-1.fc44.x86_64.rpm
```

Keep the same installation method and prefix. Remove manual system or user-local duplicates before switching to native packages so Qt cannot load an older copy. Existing credentials, selections, colors, preferences, and quota-history files need no migration. Package removal does not delete those user-owned records.

See the [0.6.0 package guide](https://github.com/kyaulabs/kodometer/blob/v0.6.0/docs/packaging.md) and [tagged source-build instructions](https://github.com/kyaulabs/kodometer/blob/v0.6.0/README.md#build-and-install). Container provisioning helpers are not desktop installers. Compiled applets are not `kpackagetool6` ZIPs.

## ⚠️ Compatibility and known limitations

- Plasma/libplasma 6.4+, Qt 6.4+, and KDE Frameworks 6 remain required. Supported binary targets are Arch rolling, Ubuntu 26.04 LTS, and Fedora 43/44 on x64. There are no ARM, generic Debian, or RHEL packages; Ubuntu 24.04's standard Plasma stack is too old.
- Packages are distribution/ABI-specific and do not bundle Qt/KDE libraries. No hosted APT/DNF repository or automatic desktop updater is provided.
- Held chart values do not identify when usage changed between refreshes. Reset steps use observation timestamps, not reconstructed activity. History remains bounded to 30 days and the existing count/storage limits. Changing credentials or accounts still isolates history.
- Symbolic artwork varies by icon theme. Popup content remains paginated within the screen-height budget; settings dialogs and horizontal provider navigation can still scroll.
- Provider support is unchanged: Gemini is Code Assist OAuth quota, Kimi is For Coding rather than Moonshot, and xAI is developer Management API billing rather than Grok subscriptions. Only selected accounts are polled. See the [tagged provider contract](https://github.com/kyaulabs/kodometer/blob/v0.6.0/README.md).

## 🔒 Security and privacy

No authentication endpoints, credentials, polling, notification policy, or persisted-history format change. Chart holding and hover inspection are presentation-only. No provider CLI execution, browser-session access, additional requests, or new history records are introduced. Secrets and private selectors remain in KWallet; OAuth rotation remains pinned to the originating provider-owned file.

History clearing still asks for confirmation and removes recorded quota observations, not credentials, preferences, or provider-reported billing history. Packages do not remove user-owned data.

Published assets are immutable. SHA-256 files detect corruption but do not establish publisher identity. The workflow creates an annotated source tag, not an independently GPG-signed tag, and does not independently sign DEB/RPM payloads. Reviewed development commits retain their GPG signatures through merge commits.
